# Setup

This repo *is* your GitHub profile page. Everything renders straight from
this README — no external image hosts, no third-party badge services, no
`<script>` tags (GitHub strips those anyway). Every card and section
header is plain SVG with SMIL/CSS animation baked in, regenerated by a
script and committed by a scheduled Action.

## 1. One-time repo setup

1. Create a repository named **exactly** your GitHub username, e.g.
   `github.com/yourname/yourname`. GitHub automatically shows that repo's
   README on your profile page.
2. Push the contents of this folder to it.
3. Under **Settings → Actions → General → Workflow permissions**, select
   *"Read and write permissions"* so the daily workflow can commit back to
   the repo using the default `GITHUB_TOKEN` (no personal access token
   needed — public follower/repo/star counts and your public contribution
   calendar are both readable with the default token).

## 2. Generate everything once locally (optional)

The Action does this daily, but you can preview locally:

```bash
pip install -r scripts/requirements.txt

python scripts/generate_headers.py assets/headers
GITHUB_TOKEN=<a token, or omit for demo data> python scripts/generate_streak.py   <your-username> assets/streak.svg
GITHUB_TOKEN=<a token, or omit for demo data> python scripts/generate_activity.py <your-username> assets/activity.svg
GITHUB_TOKEN=<a token, or omit for demo data> python scripts/generate_langs.py    <your-username> assets/langs.svg
GITHUB_TOKEN=<a token, or omit for demo data> python scripts/generate_year.py     <your-username> assets/year.svg
```

Without a token, each script falls back to demo data so the page still
renders — that's what's committed initially.

## 3. Fill in your details

Open `README.md` and replace:

- the name and tagline at the top
- the About paragraph
- the Stack table
- the four project entries and links
- the Thoughts & Things placeholder
- the site / Instagram / LinkedIn / email links at the bottom

## 4. Let it run

`.github/workflows/update-profile.yml` runs daily, regenerates
`assets/streak.svg`, `assets/activity.svg`, `assets/langs.svg`,
`assets/year.svg` and the section headers, and **only commits if the
output actually changed** — quiet days don't produce noise in your commit
history. You can also trigger it manually from the Actions tab.

## How the animation works without JavaScript

GitHub sanitizes embedded SVGs (serves them as `text/plain` and strips
`<script>`), but it does **not** strip:
- SMIL animation elements (`<animate>`, `<animateTransform>`, `<set>`) —
  the same mechanism behind popular "typing" SVGs.
- Inline `<style>` blocks with CSS `@keyframes` — used for the reveal,
  sweep, and bar-grow effects.

Both run entirely inside the SVG document itself once your browser
renders the `<img>`, so nothing depends on external scripts or services.

`assets/activity.svg`, `assets/langs.svg`, `assets/year.svg`,
`assets/streak.svg` and the headers all additionally use a
`@media (prefers-color-scheme: dark)` block in their own `<style>`, so
each switches palette automatically based on the *viewer's* OS/browser
theme — independent of whatever GitHub.com's own light/dark toggle is
set to.

`assets/year.svg` renders its contribution grid as monospace characters
(same idea as an ASCII-art portrait) and uses SVG's `textLength` /
`lengthAdjust="spacing"` on each row so the columns line up with the
month labels regardless of which specific monospace font a given browser
substitutes.

## File map

```
README.md                          the profile page
assets/streak.svg                  generated current/longest streak card
assets/activity.svg                generated animated contribution-activity card
assets/langs.svg                   generated top-languages card (by bytes / by repo)
assets/year.svg                    generated character-ramp contribution calendar
assets/headers/header-*.svg        generated section-title graphics
scripts/theme.py                   shared monochrome palette/fonts
scripts/generate_streak.py         GitHub API -> streak SVG (light/dark adaptive)
scripts/generate_activity.py       GitHub API -> animated activity chart SVG (light/dark adaptive)
scripts/generate_langs.py          GitHub API -> languages SVG (light/dark adaptive)
scripts/generate_year.py           GitHub API -> character-ramp calendar SVG (light/dark adaptive)
scripts/generate_headers.py        section title SVGs (light/dark adaptive)
.github/workflows/update-profile.yml   daily regenerate-and-commit job
```
